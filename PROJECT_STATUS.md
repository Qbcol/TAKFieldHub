# Field TAK Hub 2.3.0 — Project Status

## Current state

The repository contains the current 2.3.0 Hub + Builder source intended for the next external test cycle.

### Android

- Simple Mode and Advanced Mode finalized for the 2.3.0 test workflow.
- `.ftak` import retained.
- Provisioning, enrollment and Data Package QR workflows retained.
- Smart Diagnosis and Recovery retained.
- Meshtastic HYBRID flow and runtime diagnostics retained.
- Back navigation improved: internal screens use normal back navigation; the home screen requires a second quick back press before moving the task to the background.
- Polish and English resources retained.
- Current Field TAK Hub icon and author-support panel are included.

### Windows Builder

- Project workspace creation and repair retained.
- `.ftak` packaging, signing and validation retained.
- Meshtastic configuration and gateway metadata retained.
- Enrollment and package distribution workflow retained.

### Repository / CI

- Source Gate and static contract tests are included.
- Android, Windows Builder and release GitHub Actions workflows are included.
- Release artifacts are generated by CI instead of being committed to the repository.

## Security

The public repository must not contain MQTT passwords, private keys, permanent tokens, secret-bearing enrollment URIs or private Meshtastic Channel URLs.

## Release state

This repository is prepared for the 2.3.0 external test cycle. GitHub Actions remains the authoritative environment for Android/Windows compilation and release artifact generation.
