# Changelog

## 2.3.0 — Test release

### Android

- Simplified Simple Mode for field users.
- Added structured Advanced Mode with clear OpenTAKServer sections for **User Enrollment** and **Data Packages**.
- Retained `.ftak` import as a first-class action.
- Added one-tap Meshtastic configuration handoff when the package contains a prepared channel configuration.
- Added Smart Diagnosis and Recovery workflow.
- Improved Meshtastic runtime/link diagnostics.
- Added normal back navigation between internal screens.
- Added double-back protection on the home screen before moving the app to the background.
- Added updated Field TAK Hub application icon.
- Added bilingual author-support panel with BuyCoffee QR and link.
- Maintained Polish / English resource parity.

### Meshtastic

- HYBRID deployment remains hardware-neutral.
- `channel.url` and optional `profile.json` remain supported.
- Gateway metadata is kept separate from radio I/O and secrets.
- BLE/USB and radio communication remain owned by the Meshtastic/ATAK layer.

### Windows Builder

- Project folder automation retained.
- `.ftak` schema v2 retained.
- Enrollment, Data Package and Meshtastic packaging retained.
- Package validity and QR validity settings retained.

### CI / validation

- Source Gate and static contract suite included in the repository.
- Android, Windows Builder and release GitHub Actions workflows retained.
- Release artifacts are generated by CI rather than committed to Git.
