FIELD TAK HUB 2.0.1 RC4 / BUILDER 2.1.0 RC7 — GITHUB PRZEZ PRZEGLĄDARKĘ

1. Wgraj całą zawartość tej paczki do repozytorium Qbcol/TAKFieldHub.
2. Jeśli przeglądarka nie pozwala łatwo wgrać ukrytego folderu .github:
   - wejdź w Actions -> New workflow / set up a workflow yourself,
   - utwórz kolejno pliki .github/workflows/source-gate.yml, android.yml,
     windows-builder.yml i release.yml,
   - skopiuj ich treść z folderu WORKFLOWS_FOR_GITHUB_WEB.
3. Uruchom kolejno Source Gate, Android i Windows Builder.
4. Android RC4 ma trzy osobne skanery QR:
   - Przygotuj telefon (Field TAK provisioning/.ftak),
   - Enrollment użytkownika (QR z UI OpenTAKServer),
   - Data Packages (QR/link z OpenTAKServer do importu w ATAK).
5. Builder RC7 zachowuje dystrybucję LAN, chmurę/HTTPS, Google Drive oraz import ZIP 1.x.
